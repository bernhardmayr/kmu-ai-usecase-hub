# KMU AI Use Case Hub

Eine mobile Web-App, mit der kleine und mittlere Unternehmen KI-Use-Cases erfassen, bewerten, priorisieren und exemplarisch ausführen können.

## Enthaltene Funktionen

- Dashboard mit Portfolio-Kennzahlen
- Use-Case-Verwaltung mit Suche und Filtern
- AI Canvas mit Output, Action, Impact, Daten, Risiken und Metriken
- Nutzen-Machbarkeits-Matrix
- Drei interaktive Beispieldemos
- Anlage eigener Use Cases
- Lokale Speicherung im Browser
- JSON-Export des Portfolios
- Responsive Darstellung für Smartphone, Tablet und Desktop

## Demo-Modus

Die Beispiele laufen vollständig im Browser. Es werden keine Daten an externe KI-Dienste übertragen und keine realen Geschäftsaktionen ausgelöst.

## Veröffentlichung

Der Inhalt wird über den Workflow in `.github/workflows/pages.yml` automatisch auf GitHub Pages veröffentlicht.

## Datenschutz und Persistenz

Selbst angelegte Use Cases werden in dieser MVP-Version ausschließlich im lokalen Browser-Speicher des verwendeten Geräts gespeichert. Für organisationsweite Zusammenarbeit wird später ein Backend mit Authentifizierung und zentraler Datenbank benötigt.
